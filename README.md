# tgmine

Моніторинг ударів по РФ за публічними Telegram-каналами. Збирає повідомлення,
розбирає на події з координатами, будує статичний сайт: зведення за період,
звіт за добу, карта-програвач нальоту.

Без бекенду й API-ключів — усе на статиці, хоститься безкоштовно.

![стек](https://img.shields.io/badge/python-3.9+-blue) ![дані](https://img.shields.io/badge/дані-OSM_%7C_GeoNames_%7C_NaturalEarth-green)

## Що воно показує

| Сторінка | Що там |
|---|---|
| **Зведення** | 31 доба, спостереження, апарати, ППО, топ регіонів і найгарячіших цілей |
| **Звіт за добу** | KPI з порівнянням до норми, хід доби по годинах, регіони, активність біля цілей |
| **Карта доби** | програвач: рух у часі, треки, області під тривогою, шар військових цілей |
| **Що зараз** | стан за останні 6 годин з індикатором свіжості даних |

## Швидкий старт

```bash
pip3 install -r requirements.txt

python3 sync.py --rebuild        # зібрати сховище з наявного кешу (у вікні сховища; --all-dates — усе сире)
python3 site.py --raids          # згенерувати сайт
python3 -m http.server -d site 8000
```

Відкрити http://localhost:8000

## Тести

```bash
python3 -m unittest discover -s tests -t .
```

Без залежностей, лише stdlib. Те, що потребує газетира чи зібраного сховища,
пропускається на чистому клоні. Запускаються в CI перед збором даних.

## Повний конвеєр з нуля

Порядок важливий — кроки залежать один від одного:

```bash
python3 fetch_targets.py     # 1. військові обʼєкти з OSM (~10 хв, мережа)
python3 refineries.py        # 2. + курований список НПЗ і нафтотерміналів
python3 name_targets.py      # 3. уточнити generic-назви через газетир
python3 sync.py --since 30d  # 4. зібрати пости й розібрати у сховище
python3 rank_targets.py      # 5. порахувати важливість цілей
python3 mkregions.py         # 6. межі областей (разово, потребує Natural Earth)
python3 site.py --raids      # 7. зібрати сайт
```

Потрібні дані, яких нема в репозиторії (тягнуться разово):

```bash
mkdir -p gazetteer && cd gazetteer
curl -sLO https://download.geonames.org/export/dump/RU.zip
curl -sLO https://download.geonames.org/export/dump/UA.zip
curl -sLO https://naciscdn.org/naturalearth/10m/cultural/ne_10m_admin_1_states_provinces.zip
unzip -oq '*.zip' && rm -f *.zip
```

## Щоденне оновлення

```bash
python3 sync.py                       # доваантажити нове
python3 site.py --days 10 --raids     # перебудувати свіже
```

Ідемпотентно — повторний запуск нічого не ламає, придатне для cron.

## Джерела даних

| Що | Звідки | Ліцензія |
|---|---|---|
| Повідомлення | `t.me/s/<channel>` (веб-превʼю) | публічні пости |
| Топоніми | GeoNames | CC-BY |
| Межі областей | Natural Earth 10m admin-1 | public domain |
| Військові обʼєкти | OpenStreetMap / Overpass | ODbL |
| НПЗ і термінали | курований список | — |

Канали: `lpr1_treugolnik`, `kupolrussia`, `vrv_radar`. Змінюються в `sync.py`.

## Конфігурація

Уся предметна специфіка — в `configs/ru-monitor.yaml`, код універсальний:

```yaml
tags:        # чим тегувати повідомлення
  БПЛА: ["БПЛА", "дрон\\w*", "шахед\\w*"]
entities:    # що витягувати: тип -> канонічна назва -> варіанти написання
  регіон:
    Бєлгородська: ["Белгородск\\w*", "\\bБгд\\b", "Шебекин\\w*"]
noise:       # реклама, збори, вербування — ховається з публічних сторінок
  - "поддерж\\w+\\s+канал"
geo:         # центроїди для карти
  Бєлгородська: [50.5977, 36.5858]
```

Для іншої теми пишеться свій конфіг — код не змінюється.

## Важливо про дані

Це дані про **повідомлення**, а не про факти:

- Щільність залежить від кількості спостерігачів, не лише від активності
- Незалежних джерел два, і вони покривають різні території: другим голосом
  підтверджено лише 3.1% спостережень, у 35 регіонах із 39 джерело фактично одне
- Наслідків ударів канали майже не публікують — «збито» і «вибухів» занижені
- «Заявлено апаратів» — нижня межа, число є лише в 3.3% повідомлень
- Координати — центр населеного пункту, не місце удару
- Треки руху — статистичні гіпотези. Нуль-тест рахується для кожної доби окремо
  й показується на самій сторінці: медіана z по 31 ночі = 0.00, значущими є
  лише 4 ночі з 31

Ці застереження виведені на самих сторінках, не сховані в документації.
