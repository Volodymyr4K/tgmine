# А/Б для розбору: зібрати сховище в іншу теку й порівняти

Інструменти, якими міряли правки 20–21 вересня 2026 (пуски, геокод). Не в CI,
не в тестах — запускаються руками з кореня репозиторію.

| скрипт | що робить |
|---|---|
| `build_into.py <тека>` | зібрати сховище ПОТОЧНИМ кодом у довільну теку (вікно — як у `sync.py --rebuild`, порядок каналів — як `CHANNELS`) |
| `build_opt.py <тека>` | те саме з вимикачами для ізольованих замірів: `NO_LAUNCH=1` (без `store.launch_origin`), `NO_SEAT=1` (без «місто замість своєї області») |
| `cmp.py <А> <Б>` | пари подій за спільним `id`: що змінилось (вид, шар, тип, `geo_conf`, рух координати >5 км) + метрика пусків за арбітром |
| `launch_audit.py <тека>` | поіменно: крапки-пуски не на підконтрольній Україні; пуски без крапки, хоча є «от X» |
| `night_launches.py <дата> …` | поіменно: які пуски підсвітить редактор у ніч і що в їхніх текстах |

Приклад — виміряти одну правку окремо:

```bash
NO_LAUNCH=1 python3 tools/ab/build_opt.py /tmp/storeB   # усе, крім правила пусків
python3 tools/ab/build_opt.py /tmp/storeC               # усе
python3 tools/ab/cmp.py /tmp/storeB /tmp/storeC         # = лише правило пусків
```

Пастки, на які вже наступали:
- **Змінні середовища — кожна окремим словом перед командою**
  (`NO_SEAT=1 NO_LAUNCH=1 python3 …`). Оболонка тут zsh, і `env $envs cmd`
  з `envs="A=1 B=1"` НЕ розбиває рядок: дійшла одна змінна, і «ізольований»
  замір виявився змішаним.
- **Збірка ~4 хв і 1–2 ГБ памʼяті; дві паралельно — ризик OOM** (тести вже
  вбивало кодом 137). Збирати по черзі.
- **«До» — сховище, зібране СТАРИМ кодом** (`git show <base>:store/...` або
  збірка до правки), а не поточним: стенд, що рахує обидві сторони новим кодом,
  показує нуль.
- **Арбітр не має бути частиною правила.** Для пусків арбітр — `depth == 0`
  (підконтрольна Україні); у саме правило він не входить, інакше замір — коло.
- **Поіменно, а не числом, і на ВИПАДКОВИХ ночах.** Вада «готовит очередной
  массовый запуск» знайшлась лише на випадковій ночі; на п'яти вибраних за
  кількістю пусків її не було видно.
